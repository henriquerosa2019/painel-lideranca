# Bússola da Líder 🧭 | Guia & Motivação Diária

Aplicação web mobile-first (Progressive Web App - PWA) desenvolvida especialmente para gestoras em fase de transição de cargo, enfrentando o desafio de liderar equipes desmotivadas e lidar com alta gestão sem sobrecarga física ou mental.

---

## 🚀 Como Publicar na Vercel (Em menos de 1 minuto)

O projeto já está 100% pronto e configurado com `vercel.json`. Escolha qualquer um dos métodos abaixo:

### Método 1: Direto pelo Navegador (Sem instalar nada)
1. Acesse **[vercel.com](https://vercel.com)** e faça login (com sua conta do Google ou GitHub).
2. Acesse a tela de novo projeto: **[vercel.com/new](https://vercel.com/new)**.
3. Se estiver usando repositório GitHub, basta conectar este projeto e clicar em **Deploy**.
4. **Ou simplesmente arraste** a pasta `painel-lideranca` diretamente na tela da Vercel!
5. Em 20 segundos a Vercel gerará um link público (ex: `https://bussola-lider.vercel.app`).

### Método 2: Pelo Terminal (Vercel CLI)
Se tiver o Node.js / Vercel instalado, abra o PowerShell nesta pasta:
```bash
cd C:\Users\Henrique\.gemini\antigravity\scratch\painel-lideranca
npx vercel
```
- Pressione `Enter` para confirmar as perguntas padrão.
- Pronto! O link de produção será exibido na tela.

## 📱 Como Salvar no Celular como Aplicativo (Ícone na Tela Inicial)

Uma vez com o link gerado pela Vercel aberto no celular:

### No iPhone (Safari):
1. Abra o link gerado no **Safari**.
2. Toque no ícone de **Compartilhar** (quadrado com a seta para cima na barra inferior).
3. Role para baixo e selecione **"Adicionar à Tela de Início"**.
4. Toque em **Adicionar**.
5. *Pronto! Ele aparecerá como um aplicativo próprio com ícone e tela cheia.*

### No Android (Chrome):
1. Abra o link gerado no **Google Chrome**.
2. Toque no menu de **3 pontinhos** no canto superior direito.
3. Selecione **"Instalar aplicativo"** ou **"Adicionar à tela inicial"**.
4. *Pronto! Funciona offline inclusive.*
